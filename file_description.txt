# Social and Flirting Confidence Simulator - File Descriptions

## Root Directory Files

### .gitignore
Git ignore file that excludes common Python artifacts, virtual environments, logs, media files, and sensitive data like .env files from version control.

### elevenlabs_client.py
Client wrapper for ElevenLabs API to generate voice synthesis based on AI personality types. Maps personalities (playful, calm, shy) to specific voice IDs and handles text-to-speech conversion with personality-specific voice settings.

### file_description.txt
This file - contains detailed descriptions of all project files, their purposes, and key components.

### main.py
Main FastAPI application entry point. Sets up the web server, includes API routers, configures CORS, serves static files, and provides endpoints for documentation and the frontend.

### README.md
Project documentation including overview, features, installation instructions, API endpoints, project structure, and development guidelines.

### requirements.txt
Python dependencies list including FastAPI, Hume AI SDK, OpenAI, ElevenLabs, Pydantic, and other required packages.

### TODO.md
Task list for ongoing development, including voice synthesis integration, AI dialogue enhancement, and frontend improvements.

## ai_personality/ Module

### ai_personality/__init__.py
Module initialization file that exports the GPTClient class.

### ai_personality/gpt_client.py
GPT-4 client for generating AI personality-based responses. Includes personality-specific prompts, temperature settings, and conversation history management. Adds emotional gestures (e.g., *smiles*, *nods*) to responses based on personality for enhanced immersion.

## api/routes/ Module

### api/routes/conversation.py
API routes for handling conversation interactions. Processes user messages, generates AI responses using GPT client, and handles voice synthesis through ElevenLabs.

### api/routes/frs.py
Core FRS (Flirting Response Score) analysis routes. Handles calibration steps, real-time emotion streaming via WebSocket, baseline establishment, FRS computation, and video upload analysis.

### api/routes/session.py
Session management routes. Creates and ends sessions, manages scenarios and objectives, handles AI response generation with voice synthesis, and provides mode/scenario/personality options.

## core/ Module

### core/__init__.py
Empty module initialization file.

### core/constant.py
Application constants including version, name, and basic configuration values.

### core/scoring.py
FRS computation logic. Calculates Flirting Response Score from emotion data using weighted components (visual confidence, vocal fluency, emotional awareness) and determines medals/stars.

### core/session_store.py
SQLite database wrapper for persistent session storage. Manages session data, summaries, and user progress with proper schema migration.

## core/data_contract/ Module

### core/data_contract/__init__.py
Module initialization that exports enums for modes, personalities, and medals.

### core/data_contract/_static_enums.py
Defines core enumerations: DocumentationSections, Mode (social/romantic), Personality (playful/calm/shy), and Medal types for achievements.

## models/ Module

### models/models.py
Pydantic data models for API requests/responses including calibration data, emotion data, FRS results, session data, and scenario objectives.

## hume_ai/ Module

### hume_ai/hume_ai_client.py
Client for Hume AI emotion analysis API. Handles WebSocket streaming for real-time facial and vocal emotion detection, mapping Hume predictions to application emotion metrics.

## static/ Module

### static/index.html
Single-page HTML frontend with JavaScript for the web interface. Includes calibration workflow, session management, real-time video streaming, emotion metrics display, conversation simulation, and feedback presentation.
